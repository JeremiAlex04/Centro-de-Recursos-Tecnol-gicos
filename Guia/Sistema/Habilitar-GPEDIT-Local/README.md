# Habilitar Editor de Directivas de Grupo Local (gpedit.msc)

## Nombre de la herramienta
Habilitar Editor de Directivas de Grupo Local (gpedit.msc)

## Función y propósito principal
Guía/script para habilitar gpedit.msc en ediciones de Windows que no lo traen por defecto.

## Características o funcionalidades relevantes
- Permite habilitar Editor de Directivas Local

## Requisitos o dependencias
Windows; según edición puede requerir archivo/script
