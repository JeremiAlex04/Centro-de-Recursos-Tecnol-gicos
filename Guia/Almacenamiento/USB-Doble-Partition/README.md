# Crear/limpiar USB con diskpart (guía)

## Nombre de la herramienta
Crear/limpiar USB con diskpart (guía)

## Función y propósito principal
Instrucciones con diskpart para limpiar disco USB.

## Características o funcionalidades relevantes
- Comandos diskpart
- Habilitar volumen desde Administración de Equipos

## Requisitos o dependencias
Privilegios administrativos

## Instrucciones básicas de uso
1. diskpart
2. list disk
3. select disk ? (elegir USB)
4. detail disk
5. clean
Luego habilitar el volumen en Administración de Equipos.
