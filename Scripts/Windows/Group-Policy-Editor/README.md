# Habilitar Editor de Directivas de Grupo Local (gpedit.msc)

## Función
Script/guía para habilitar gpedit.msc en ediciones Windows sin soporte.

## Propósito
Habilitar la consola de directivas locales (gpedit.msc).

## Características principales
- Habilita gpedit.msc
- Requiere ejecución según script

## Requisitos
Privilegios administrativos; archivo/script indicado en origen.

## Uso básico
Descargar/ejecutar Group_Policy.bat desde el enlace provisto. Comprobar con gpedit.msc.
