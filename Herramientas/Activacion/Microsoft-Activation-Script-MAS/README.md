# Microsoft Activation Script (MAS)

## Nombre de la herramienta
Microsoft Activation Script (MAS)

## Función y propósito principal
Activación de Windows/Office mediante métodos documentados en el proyecto MAS.

## Características o funcionalidades relevantes
- Script para activación
- Soporta distintos productos según documentación oficial

## Requisitos o dependencias
Ejecutar con privilegios según indicaciones; revisar documentación oficial.

## Instrucciones básicas de uso
Página oficial: https://massgrave.dev/
Comando (según documentación):
```powershell
irm https://get.activated.win | iex
```
