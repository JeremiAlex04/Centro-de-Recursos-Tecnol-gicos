# Chris Titus Tech Windows Utility

## Nombre de la herramienta
Chris Titus Tech Windows Utility

## Función y propósito principal
Script de instalación/configuración/mantenimiento para Windows.

## Características o funcionalidades relevantes
- Automatiza tareas comunes de Windows

## Requisitos o dependencias
Windows PowerShell (Administrador)

## Instrucciones básicas de uso
Ejecutar en PowerShell como administrador:
```powershell
iwr -useb https://christitus.com/win | iex
```
