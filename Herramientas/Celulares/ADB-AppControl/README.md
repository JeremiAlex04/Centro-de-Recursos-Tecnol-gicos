# ADB AppControl

## Nombre de la herramienta
ADB AppControl

## Función y propósito principal
Administración/desinstalación de aplicaciones Android mediante ADB (AppControl).

## Características o funcionalidades relevantes
- Interfaz para gestionar apps Android con ADB
- Permite desinstalar apps sin root en muchos casos

## Requisitos o dependencias
Requiere ADB habilitado/dispositivo conectado.

## Instrucciones básicas de uso
Ver enlace oficial: https://adbappcontrol.com/en/
